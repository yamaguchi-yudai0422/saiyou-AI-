# Noesia 採用補助システム

Noesia API を使って、面接内容の記録と評価補助を行う Windows 向けデスクトップアプリです。  
面接官向けの採点モードと、応募者向けの企業評価モードの 2 つを備えています。

## できること

- マイク音声と PC の再生音声を文字起こしして会話ログを作成
- 面接官モードで、企業情報・履歴書・面接ログをもとに採用判断の補助コメントを生成
- 応募者モードで、企業情報と会話ログをもとに企業との相性コメントを生成
- API キーや音声デバイス設定をアプリ内で保存

## アプリの構成

- `main.py`: FastAPI とデスクトップ表示の起点
- `audio_service.py`: 音声入力デバイス取得と文字起こし処理
- `ai_service.py`: Noesia API への問い合わせ
- `static/`: 画面 UI

## 動作環境

- Windows
- Python 3.11 以上を推奨
- マイク入力
- ループバック録音に対応した音声デバイス

## セットアップ

```powershell
./install.bat
```

または手動で以下を実行します。

```powershell
pip install -r requirements.txt
```

## 起動方法

```powershell
./run.bat
```

起動後、画面右上の設定ボタンから Noesia API キーを入力してください。

## 使い方

### 面接官モード

1. 企業情報や募集背景を入力
2. 履歴書を貼り付け
3. 音声認識または手入力で面接ログを作成
4. `面接終了` を押して採用判断の補助コメントを生成

### 応募者モード

1. 企業情報を入力
2. 会話ログを記録
3. `終了して企業を評価する` を押して企業評価コメントを生成

## ビルド

```powershell
./build.bat
```

ビルド後は `dist/NoesiaHR` が出力されます。

## 個人情報・秘密情報について

- API キーはソースコードに含めず、初回設定後にローカルの `config.json` に保存されます
- `config.json`、キャッシュ、ビルド成果物は Git へ含めない設定にしています
- 実際の面接ログ、履歴書、企業情報などの個人情報はリポジトリへ保存しない運用を想定しています

## 公開時の注意

- push 前に `config.json` が生成されていないか確認してください
- 実在の応募者情報や面接記録はコミットしないでください
- GitHub アカウント名やコミット作者名は、リポジトリ内容とは別に Git の履歴として公開される点に注意してください
