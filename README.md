# Noesia 採用補助AI

Noesia API を活用して、面接の記録・質問・評価を補助する Windows 向けアプリです。面接の最終判断は人が行い、AI は判断材料の整理と対話をサポートします。

## ダウンロード

[**Windows版をダウンロード（NoesiaHR v1.0.2）**](https://github.com/yamaguchi-yudai0422/saiyou-AI-/releases/download/v1.0.2/NoesiaHR-v1.0.2-windows.zip)

ダウンロードした ZIP を解凍し、フォルダ内の `NoesiaHR.exe` を起動してください。

録音前に「音声テスト」でマイクとPC音声を確認できます。PC音声は、選択した再生デバイスから出るすべての音を拾います。音声テストの結果は面接ログに追加されません。

## はじめに

1. [Noesia](https://noesia.jp/) の育成モードで質問に答え、AI に人格を学習させます。
2. Noesia の有料 API で API キーを発行します。
3. 本アプリを起動し、画面右上の設定から API キーを入力します。
4. 起動時に、面接官モードまたは志望者モードを選びます。

API キーと音声デバイスの設定は、利用する PC 内に保存されます。

## 2つのモード

### 面接官モード

- マイク音声と PC の再生音声を文字起こしして、面接ログを作成
- 企業情報、履歴書、面接内容をもとに、採用判断の補助コメントを生成
- 履歴書は PDF、画像、テキスト入力、貼り付けに対応

面接の記録漏れを減らし、面接後に判断材料を整理できます。

### 志望者モード

- Noesia で育成した AI 人格が、志望者の目線で「自分ならこの会社に合うか」を考察
- 面接中の会話をもとに、次に聞くとよい質問をリアルタイムで提案
- 企業と応募者の相性を多面的に考えるための補助に利用

## 動作に必要なもの

- Windows PC
- Noesia API キー（有料）
- マイク入力
- PC の再生音声も記録する場合は、ループバック録音に対応した音声デバイス

## データの扱い

- API キーはアプリの設定として利用する PC に保存されます。
- 履歴書の PDF・画像は端末内で読み取ります。採点時には抽出したテキストを Noesia API に送信します。
