# Noesia 採用補助システム

Noesia API を使って、面接内容の記録と評価補助を行う Windows 向けデスクトップアプリです。  
面接官向けの採点モードと、応募者向けの企業評価モードの 2 つを備えています。

起動時にモード選択画面を表示し、面接官モードと志望者モードを選べます。

## できること

- マイク音声と PC の再生音声を文字起こしして会話ログを作成
- 面接官モードで、企業情報・履歴書・面接ログをもとに採用判断の補助コメントを生成
- 履歴書はPDF読込、直接入力、文字ファイル読込、画像OCR、クリップボード貼り付けに対応
- 志望者モードで、Noesia人格本人が志望者となり、自分ならその企業に合うかを一人称で判定
- 録音中の会話から、Noesia人格本人が志望者として次に聞く質問をリアルタイムに提案（生成中も録音継続）
- 会社情報・履歴書を残したまま、面接内容とNoesiaコメントを個別にクリア
- API キーや音声デバイス設定をアプリ内で保存

## アプリの構成

- `main.py`: FastAPI とデスクトップ表示の起点
- `audio_service.py`: 音声入力デバイス取得と文字起こし処理
- `ai_service.py`: Noesia API への問い合わせ
- `ocr_service.py`: Windows内蔵OCRによる履歴書画像の文字抽出
- `static/`: 画面 UI

## 動作環境

- Windows
- 日本語の履歴書画像を読む場合は、Windowsの日本語言語機能
- Python 3.11 以上を推奨
- マイク入力
- ループバック録音に対応した音声デバイス

## セットアップ

```powershell
./install.bat
```

または手動で以下を実行します。

```powershell
pip install -r requirements.txt
```

## 起動方法

```powershell
./run.bat
```

起動後、画面右上の設定ボタンから Noesia API キーを入力してください。

## 使い方

### 面接官モード

1. 企業情報や募集背景を入力
2. 履歴書PDFを読み込み（文字入りPDFは直接抽出、スキャンPDFはページごとにローカルOCR）。直接入力、文字ファイル、画像OCR、貼り付けも利用可能
3. 音声認識または手入力で面接ログを作成
4. `面接終了` を押して採用判断の補助コメントを生成

### 応募者モード

1. 企業情報を入力
2. 会話ログを記録
3. 録音中に必要に応じて `質問を考える` を押し、その時点までの会話から次の質問を生成
4. `Noesia なら合うか評価する` を押し、Noesia人格本人の目線で企業との相性コメントを生成

## ビルド

```powershell
./build.bat
```

ビルド後は `release/NoesiaHR/NoesiaHR.exe` が出力されます。配布するときは、依存ファイルが入った `_internal` を含めて `release/NoesiaHR` フォルダごと渡してください。

### 配布時の注意（ギガファイル便などでダウンロードした場合）

インターネット経由でダウンロードした ZIP は、Windows が「ブロック（Mark of the Web）」を付けます。この状態で解凍すると `_internal` 内の `Python.Runtime.dll` が読み込めず、起動時に次のエラーが出ます。

```
RuntimeError: Failed to resolve Python.Runtime.Loader.Initialize from ...\_internal\pythonnet\runtime\Python.Runtime.dll
```

**受け取った側の対処法（どちらか）:**

1. **解凍前に ZIP を許可する（推奨）**
   ダウンロードした ZIP を右クリック →「プロパティ」→ 下部の「**許可する（Unblock）**」にチェック → OK → その後に解凍する。

2. **解凍後にまとめて解除する**
   すでに解凍済みなら、`NoesiaHR.exe` があるフォルダで PowerShell を開き、次を実行する。

   ```powershell
   Get-ChildItem -Path ".\NoesiaHR" -Recurse | Unblock-File
   ```

**その他の起動エラー時の確認点:**

- 画面表示に .NET Framework 4.6.1 以上が必要です（Windows 11 は標準搭載）。
- フォルダのパスに日本語などが含まれても通常は動作しますが、上記で解決しない場合は `C:\NoesiaHR\` のような英数字のみのパスへ移動して試してください。

> 配布メッセージに「ZIP を右クリック →『プロパティ』→『許可する』にチェック → 解凍してください」と一言添えると、受け取った側のエラーを防げます。

配布版にはWeb由来DLLの読み込み設定を含む `NoesiaHR.exe.config` を同梱しています。PC側の.NET互換性で通常画面を開けない場合は、Microsoft Edgeのアプリ画面へ自動的に切り替わります。

## 個人情報・秘密情報について

- API キーはソースコードに含めず、初回設定後にローカルの `config.json` に保存されます
- `config.json`、キャッシュ、ビルド成果物は Git へ含めない設定にしています
- 実際の面接ログ、履歴書、企業情報などの個人情報はリポジトリへ保存しない運用を想定しています
- 履歴書PDF・画像の解析は端末内で実行され、ファイルそのものは保存・外部送信されません。抽出した履歴書テキストは採点時にNoesia APIへ送られます
