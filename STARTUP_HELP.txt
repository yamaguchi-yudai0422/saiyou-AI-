NoesiaHR が起動しない場合
===========================

ダウンロードした ZIP には、Windows のセキュリティ保護が付くことがあります。

1. 解凍前の ZIP を右クリックして「プロパティ」を開きます。
2. 画面下部に「許可する」または「ブロックの解除」がある場合はチェックします。
3. 「OK」を押し、ZIP をもう一度解凍します。
4. 解凍した NoesiaHR フォルダ内の NoesiaHR.exe を起動します。

改善しない場合
---------------

- Windows Update を実行してください。
- Microsoft Edge を最新版へ更新してください。
- Microsoft .NET Framework 4.8 をインストールまたは修復してください。

注意
----

- NoesiaHR.exe だけを移動せず、NoesiaHR フォルダを丸ごと使用してください。
- _internal フォルダや NoesiaHR.exe.config を削除しないでください。
